# Shapeshifter: Tree of Life

A small, gentle, free browser game. Play: https://xrplove.github.io/shapeshifter-game/

Grow through five forms: **Ant → Fly → Vampire → Angel → King or Queen**. Each form has its own power, one goal, and a one-line lesson.

| Form | Power | Goal |
|---|---|---|
| Ant | Carry crumbs | Bring 5 crumbs home to the nest |
| Fly | Fly over walls | Reach the flower past the walls |
| Vampire | Night sight | Find 3 lost fireflies in the dark |
| Angel | Heal | Heal 5 wilted flowers |
| King / Queen | Gather | Lead the Ant, Fly, Vampire and Angel home to the Tree of Life |

**Controls:** arrow keys + Space, or the on-screen tap buttons on phones. 🔊 button mutes.

All art is simple shapes and all sound (per-form melodies, power sounds, soft breeze) is generated in code with the Web Audio API. Phones vibrate gently at key moments where supported. Built with [Phaser 3](https://phaser.io) from a CDN; no build step.
